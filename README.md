# Animation portfolio

Animations made with my AI animation studio on a Raspberry Pi: Gemini watches a reference, Claude builds the
animation as code (one HTML file with a deterministic `render(t)`), the Pi renders it, and I direct with notes.

**Gallery:** https://javimetro.github.io/animation-portfolio/

Every piece here is my own output. The styles were learned from references; characters, logos and text never are.
This repo is written by the studio's Publish button.
